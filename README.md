# Arab City - Roblox Roleplay Game

لعبة Roleplay مفتوحة مستوحاة من أسلوب GTA مصممة لمنصة Roblox ومناسبة لجميع الأعمار.

## المميزات الرئيسية

- **شاشة تحميل احترافية** مع شعار ونصائح وتحديثات
- **نظام القفز بالمظلة** من طائرة تحلق فوق المدينة
- **واجهة HUD متكاملة** مع أزرار سريعة وشريط صحة ورصيد مالي
- **نظام الهاتف** مع تطبيقات متعددة (كاميرا، رسائل، خرائط، إعدادات)
- **منصة Social Network** داخل اللعبة (نشر صور، إعجابات، تعليقات، متابعة)
- **نظام التصوير** بكاميرات متعددة المستويات
- **نظام العقارات** الواقعي (شراء، بيع، تأجير المنازل)
- **نظام السيارات** (مدنية، رياضية، فاخرة، نادرة)
- **نظام الوظائف** (شرطي، سائق أجرة، مصور، طبيب، إطفاء، وغيرها)
- **نظام الرتب** المدفوعة (VIP, Premium, Elite, Legend)
- **تأثيرات دخول** مميزة لأصحاب الرتب
- **نظام الأموال والمهمات**
- **نظام الأكواد** (Codes) لاسترداد المكافآت
- **نظام الشهرة والمتابعين**
- **نظام الطقس** (نهار، ليل، أمطار، ضباب)
- **نظام الإنجازات**
- **أحداث أسبوعية** (سباقات، مسابقات تصوير)
- **قصر الـ Owner** الخاص
- **خريطة مدينة عربية** حديثة وكبيرة

## هيكل المشروع (Rojo)

```
src/
├── server/          → ServerScriptService (سكربتات الخادم)
│   ├── Services/    → خدمات الخادم (DataManager, Economy, RealEstate, ...)
│   └── init.server.lua
├── client/          → StarterPlayerScripts (سكربتات العميل)
│   ├── Controllers/ → وحدات التحكم (HUD, Phone, Camera, Map, ...)
│   └── init.client.lua
├── shared/          → ReplicatedStorage (مشترك)
│   └── Modules/     → وحدات مشتركة (Constants, Types, Utils)
├── gui/             → StarterGui (واجهات المستخدم)
└── starter/         → StarterCharacterScripts
```

## الإعداد السريع (ملف جاهز)

1. افتح Roblox Studio
2. اختر File > Open
3. افتح ملف `ArabCity.rbxlx` الموجود في المشروع
4. اللعبة جاهزة للاختبار والنشر

## الإعداد للتطوير (Rojo)

1. تثبيت [Rojo](https://rojo.space/) v7+
2. تثبيت Rojo Plugin في Roblox Studio
3. تشغيل `rojo serve` من مجلد المشروع
4. ربط Rojo بـ Roblox Studio عبر Plugin
5. أي تعديل على ملفات `src/` ينعكس تلقائياً في Studio

### بناء ملف rbxlx من الكود

```bash
rojo build default.project.json -o ArabCity.rbxlx
```

## التقنيات

- **Luau** - لغة البرمجة الأساسية لـ Roblox
- **Rojo 7** - مزامنة الكود من الملفات إلى Roblox Studio
- **DataStoreService** - حفظ بيانات اللاعبين
- **MarketplaceService** - المشتريات والرتب
- **TweenService** - الحركات والانتقالات
- **RunService** - تحديثات كل فريم
- **CollectionService** - ربط الأجزاء بالخدمات

## الثيم البصري

- **Midnight Blue Neon** - الثيم العام للعبة (ليلي أزرق مع نيون سماوي)
- **Midnight Metropolis** - ثيم الخريطة (كحلي داكن مع خطوط سماوية)

## للمطورين الجدد

- كل الكود مقسم لخدمات مستقلة (Services) في السيرفر ووحدات تحكم (Controllers) في الكلاينت
- `Constants.lua` يحتوي جميع الإعدادات والألوان والبيانات الثابتة
- `RemoteManager.lua` يدير جميع الاتصالات بين السيرفر والكلاينت
- `DataManager.lua` يحفظ بيانات اللاعبين تلقائياً كل 120 ثانية
- الثيم اللوني موحد عبر `Constants.COLORS`
